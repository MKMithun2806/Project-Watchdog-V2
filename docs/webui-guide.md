# Watchdog Web UI Guide

The Watchdog Dashboard is a modern Next.js application that provides a centralized interface for managing security scans, visualizing network surfaces, and reviewing AI-synthesized intelligence reports.

## Features

### 1. Reports Dashboard
The landing page displays a comprehensive history of all executed scans. Each entry provides:
- **Target**: The domain or IP address scanned.
- **Date**: Precise timestamp of the scan execution.
- **Status**: Real-time status indicators (Completed, Running, Failed).

### 2. Detailed Intelligence Reports
Selecting a report opens a multi-tabbed view containing:
- **AI Summary**: A high-level, human-readable overview of the attack surface and critical vulnerabilities, generated by LLMs.
- **Detailed Report**: Raw tool outputs and granular findings from network and vulnerability scanners.
- **Network Graph**: An interactive visualization of the discovered network architecture, allowing you to explore relationships between nodes.
- **Export**: Option to download the raw data in JSON format for external analysis.

### 3. Triggering New Scans
The "New Scan" interface allows you to initiate automated reconnaissance runs directly from the browser:
- **Target Input**: Specify the target domain or infrastructure.
- **Scan Mode**: Choose from predefined profiles (Normal, Stealth, Head).
- **Execution**: Triggers the AWS Lambda orchestrator to provision ephemeral scanning resources.

## Setup & Deployment

### Prerequisites
- Node.js 18+ installed locally.
- Access to the Supabase backend used by the Watchdog pipeline.
- AWS API Gateway endpoint for the orchestrator.

### Configuration
1. Navigate to the `dashboard/` directory.
2. Create a `.env.local` file based on the provided template:
   ```bash
   NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-key
   WATCHDOG_API_URL=your-aws-api-gateway-url
   WATCHDOG_API_KEY=your-watchdog-api-key
   ```

### Running Locally
```bash
npm install
npm run dev
```
The dashboard will be available at `http://localhost:3000`.

### Production Build
```bash
npm run build
npm start
```

## Security Note
Ensure that the `.env.local` file is never committed to version control. The dashboard uses server-side environment variables for the `WATCHDOG_API_KEY` to prevent exposure to the client.
